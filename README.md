# QR Code Contact Generator

This is a simple, self-contained HTML file that generates a QR code for a vCard (contact card).

## How to Use

1.  Open the `index.html` file in any modern web browser.
2.  Fill in the contact details in the form.
3.  Click the "Generate QR Code" button.
4.  Scan the generated QR code with your phone's camera to import the contact.

## Features

*   Generates a vCard 3.0 QR code.
*   Fields for first name, last name, phone, email, company and website.
*   Uses the `davidshimjs-qrcodejs` library to generate the QR code directly in the browser.
*   No server-side processing is required.
